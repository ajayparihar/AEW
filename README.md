# AEW Application

## Version
1.2

## Description
The AEW application is a dashboard for managing projects, cities, and companies.

## Features
- Displays total projects, distinct cities, and companies.
- Clickable logo and header title to reload the page.

## Usage
1. Open `index.html` in a web browser.
2. Ensure the API endpoint for fetching project data is correctly set in `script.js`.

## Installation
Clone the repository and open `index.html` in your browser.
